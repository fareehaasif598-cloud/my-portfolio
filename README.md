# Portfolio v1

This is my Portfolio v1 midterm project for WEB101. It is a polished version of the portfolio I built throughout Weeks 1–8 using HTML, CSS, JavaScript, npm, Vite, and the GitHub API. The site includes an about section, a projects grid with filter buttons and live search, a GitHub repositories section that loads live data from my GitHub profile, and a contact section.

## Tech Stack

- HTML
- CSS
- JavaScript
- npm
- Vite
- GitHub API
- GitHub Pages

## Features

- Responsive layout for mobile, tablet, and desktop
- Project filter buttons
- Live project search
- GitHub repositories loaded from the GitHub API
- Loading and error/retry state for GitHub repositories
- Accessible labels, focus states, and readable contrast
